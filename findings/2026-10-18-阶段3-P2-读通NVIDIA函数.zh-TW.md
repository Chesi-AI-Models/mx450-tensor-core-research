## 關鍵設計：no-fault 讀取

`kernel/mx450_p2.c` 的核心安全機制：

```c
ret = copy_from_kernel_nofault(buf, (void *)target_addr, sizeof(buf));
if (ret) { pr_err("... failed: %d\n", ret); return -EFAULT; }
```

- 位址由使用者態讀 `/proc/kallsyms` 得到，透過 `module_param` 傳入
- **全程不呼叫 `kallsyms_lookup_name`**（P1 中被證明會 oops）
- `copy_from_kernel_nofault` 在頁錯誤時回傳錯誤碼而非崩潰
- 唯讀，不呼叫目標函式

### 手工反組譯

```asm
0f 1f 40 d6        nop    DWORD PTR [rax-0x2a]      ; 多位元組 NOP，函式對齊
0f 1f 44 00 00     nop    DWORD PTR [rax+rax*1+0x0]
48 83 ec 10        sub    rsp, 0x10                  ; 建立堆疊框
48 85 ff           test   rdi, rdi                  ; 檢查第 1 個參數
75 14              jne    0x...                      ; 非空則跳轉
48 8b 05 cf ea e6 ee  mov  rax, [rip-0x1115...]     ; 載入全域變數
85 d2              test   edx, edx
75 7a              jne    ...
48 83 c4 ...       add    rsp, ...
```

**可讀出的資訊**：
1. 這是真實的 C 函式（有堆疊框、參數檢查、全域變數存取）
2. 遵循 **System V AMD64 ABI**：第 1 參數在 `rdi`，第 3 參數在 `edx`
3. `test rdi, rdi; jne` → **第 1 個參數是指標且會判空**
4. `test edx, edx` → 第 3 個參數是 32 位值，也會被檢查
