# 2026-10-18 · 階段 2 補記：顯示記憶體存取嘗試（三條通道全部閉合）

## 目標

從執行中的 GPU 記憶體抓取 FECS / GPCCS 微碼，反組譯後尋找 Tensor Core 的控制邏輯。
這是軟體層最後一個未嘗試的方向。

## 通道 1 · `/dev/mem`

```
crw-r----- 1 root kmem 1, 1 /dev/mem
核心設定：CONFIG_STRICT_DEVMEM=y
        CONFIG_IO_STRICT_DEVMEM=y
```

- `dd if=/dev/mem bs=1M skip=393216 count=16` → **0 bytes copied**
- `os.lseek(fd, 0x6020000000); os.read(fd, 1MB)` → **EFAULT (Bad address, errno 14)**

**判定**：`STRICT_DEVMEM=y` 下 `/dev/mem` 僅允許存取傳統 IO 區，PCI MMIO 區域被拒絕。

## 通道 2 · `mmap` BAR1

BAR 資源佈局：

```
BAR0: 0x000000005f000000 - 0x000000005fffffff   (256 MB, 控制暫存器)
BAR1: 0x0000006020000000 - 0x000000602fffffff   (256 MB, 顯示記憶體視窗)
```

`mmap /sys/bus/pci/devices/0000:2c:00.0/resource1` **成功**，逐段掃描結果：

```
偏移            非零位元組    佔比
（64 個 4MB 段全部為空）

有資料的段數: 0 / 64
```

**判定**：256 MB 視窗**全零**。

原因分析：
1. **MX450 是 Optimus 獨顯**，`nvidia-smi` 顯示 0% 利用率、無行程 → GPU 處於 **D3cold**，
   顯示記憶體被完全斷電，內容不可見
2. NVIDIA 的 BAR1 並非「直接可讀的顯示記憶體視窗」，存取需經 PRAMIN / 分頁視窗機制，
   而不是線性 mmap

## 通道 3 · 核心模組（未實作）

要真正讀取 GPU 內部 SRAM（Falcon 的 IMEM/DMEM）或顯示記憶體任意區域，需要：

- 編譯核心模組
- 透過 NVIDIA 核心 API（`os_alloc_mem` / `nv_al_add_mapping` 等）建立對映
- 或直接操作 GPU 的 PRAMIN 視窗

**這已經不是「使用者態逆向」，而是驅動級核心開發。工作量以月計，且需要核心標頭檔與核心除錯環境。**

## 三條通道的最終狀態

| 通道 | 結果 | 障礙 |
|---|---|---|
| `/dev/mem` | ❌ EFAULT | `CONFIG_STRICT_DEVMEM=y` |
| BAR1 mmap | ❌ 全零 | GPU D3cold + BAR1 非線性顯示記憶體視窗 |
| 核心模組 | 未實作 | 需驅動級核心開發 |

## 軟體層的終點

至此，從使用者態出發的**所有**路徑都已走到盡頭：

| # | 層次 | 手段 | 結果 |
|---|---|---|---|
| 1 | 使用者態 API | NVML | 不暴露 TC 欄位 |
| 2 | 使用者態 API | CUPTI metric | `rc=38`，零 metric（含開權限） |
| 3 | 使用者態 API | 私有 ioctl | ROOT_CLIENT 通，DEVICE_0 回傳佔位句柄 |
| 4 | 系統韌體 | BIOS dump | Boot Guard 加密，無 VFCT / 無 _ROM |
| 5 | GPU 韌體 | vBIOS 提取 | GSP FWSECLIC 憑證鏈驗證 |
| 6 | GPU 韌體 | GSP 反組譯 | 完整解析，但**不含 TC 控制邏輯** |
| 7 | 顯示記憶體 | /dev/mem | STRICT_DEVMEM 拒絕 |
| 8 | 顯示記憶體 | BAR1 mmap | 全零 |
| 9 | SM 微碼 | 檔案系統 | Turing 微碼不在磁碟（只有 Kepler 的） |

**九條路徑，九次閉合。**

## 結論

Tensor Core 的限速控制點位於 **FECS/GPCCS 微碼 + 硬體配置**，兩者：

- 微碼**固化在 GPU 內部**（不透過檔案系統提供）
- 存取它需要**驅動級核心模組**，且即便讀到，微碼本身受 **FWSEC 簽章驗證**保護，無法替換

**這不是「還沒找到方法」，是「方法需要的能力超出了軟體層，且即便具備也無法改寫」。**
