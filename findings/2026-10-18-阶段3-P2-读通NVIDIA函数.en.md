## Key design: no-fault read

The core safety mechanism in `kernel/mx450_p2.c`:

```c
ret = copy_from_kernel_nofault(buf, (void *)target_addr, sizeof(buf));
if (ret) { pr_err("... failed: %d\n", ret); return -EFAULT; }
```

- the address comes from user space reading `/proc/kallsyms` and is passed in via `module_param`
- **`kallsyms_lookup_name` is never called** (proven to oops in P1)
- `copy_from_kernel_nofault` returns an error code instead of crashing on a page fault
- read-only; the target function is never called

### Manual disassembly

```asm
0f 1f 40 d6        nop    DWORD PTR [rax-0x2a]      ; multi-byte NOP, function alignment
0f 1f 44 00 00     nop    DWORD PTR [rax+rax*1+0x0]
48 83 ec 10        sub    rsp, 0x10                  ; build stack frame
48 85 ff           test   rdi, rdi                  ; check the 1st argument
75 14              jne    0x...                      ; jump if non-null
48 8b 05 cf ea e6 ee  mov  rax, [rip-0x1115...]     ; load a global variable
85 d2              test   edx, edx
75 7a              jne    ...
48 83 c4 ...       add    rsp, ...
```

**What can be read out**:
1. this is a real C function (stack frame, argument checking, global variable access)
2. it follows the **System V AMD64 ABI**: the 1st argument in `rdi`, the 3rd in `edx`
3. `test rdi, rdi; jne` → **the 1st argument is a pointer and gets a null check**
4. `test edx, edx` → the 3rd argument is a 32-bit value and is also checked
