# 2026-10-18 · 阶段 2 补记：显存访问尝试（三条通道全部闭合）

## 目标

从运行中的 GPU 内存抓取 FECS / GPCCS 微码，反汇编后寻找 Tensor Core 的控制逻辑。
这是软件层最后一个未尝试的方向。

## 通道 1 · `/dev/mem`

```
crw-r----- 1 root kmem 1, 1 /dev/mem
内核配置：CONFIG_STRICT_DEVMEM=y
        CONFIG_IO_STRICT_DEVMEM=y
```

- `dd if=/dev/mem bs=1M skip=393216 count=16` → **0 bytes copied**
- `os.lseek(fd, 0x6020000000); os.read(fd, 1MB)` → **EFAULT (Bad address, errno 14)**

**判定**：`STRICT_DEVMEM=y` 下 `/dev/mem` 仅允许访问传统 IO 区，PCI MMIO 区域被拒绝。

## 通道 2 · `mmap` BAR1

BAR 资源布局：

```
BAR0: 0x000000005f000000 - 0x000000005fffffff   (256 MB, 控制寄存器)
BAR1: 0x0000006020000000 - 0x000000602fffffff   (256 MB, 显存窗口)
```

`mmap /sys/bus/pci/devices/0000:2c:00.0/resource1` **成功**，逐段扫描结果：

```
偏移            非零字节    占比
（64 个 4MB 段全部为空）

有数据的段数: 0 / 64
```

**判定**：256 MB 窗口**全零**。

原因分析：
1. **MX450 是 Optimus 独显**，`nvidia-smi` 显示 0% 利用率、无进程 → GPU 处于 **D3cold**，
   显存被完全断电，内容不可见
2. NVIDIA 的 BAR1 并非"直接可读的显存窗口"，访问需经 PRAMIN / 分页窗口机制，
   而不是线性 mmap

## 通道 3 · 内核模块（未实施）

要真正读取 GPU 内部 SRAM（Falcon 的 IMEM/DMEM）或显存任意区域，需要：

- 编译内核模块
- 通过 NVIDIA 内核 API（`os_alloc_mem` / `nv_al_add_mapping` 等）建立映射
- 或直接操作 GPU 的 PRAMIN 窗口

**这已经不是"用户态逆向"，而是驱动级内核开发。工作量以月计，且需要内核头文件与内核调试环境。**

## 三条通道的最终状态

| 通道 | 结果 | 障碍 |
|---|---|---|
| `/dev/mem` | ❌ EFAULT | `CONFIG_STRICT_DEVMEM=y` |
| BAR1 mmap | ❌ 全零 | GPU D3cold + BAR1 非线性能存窗口 |
| 内核模块 | 未实施 | 需驱动级内核开发 |

## 软件层的终点

至此，从用户态出发的**所有**路径都已走到尽头：

| # | 层次 | 手段 | 结果 |
|---|---|---|---|
| 1 | 用户态 API | NVML | 不暴露 TC 字段 |
| 2 | 用户态 API | CUPTI metric | `rc=38`，零 metric（含开权限） |
| 3 | 用户态 API | 私有 ioctl | ROOT_CLIENT 通，DEVICE_0 返回占位句柄 |
| 4 | 系统固件 | BIOS dump | Boot Guard 加密，无 VFCT / 无 _ROM |
| 5 | GPU 固件 | vBIOS 提取 | GSP FWSECLIC 证书链验证 |
| 6 | GPU 固件 | GSP 反汇编 | 完整解析，但**不含 TC 控制逻辑** |
| 7 | 显存 | /dev/mem | STRICT_DEVMEM 拒绝 |
| 8 | 显存 | BAR1 mmap | 全零 |
| 9 | SM 微码 | 文件系统 | Turing 微码不在磁盘（只有 Kepler 的） |

**九条路径，九次闭合。**

## 结论

Tensor Core 的限速控制点位于 **FECS/GPCCS 微码 + 硬件配置**，两者：

- 微码**固化在 GPU 内部**（不通过文件系统提供）
- 访问它需要**驱动级内核模块**，且即便读到，微码本身受 **FWSEC 签名验证**保护，无法替换

**这不是"还没找到方法"，是"方法需要的能力超出了软件层，且即便具备也无法改写"。**
