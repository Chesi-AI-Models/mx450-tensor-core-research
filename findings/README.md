## 硬事实速查

| 项 | 值 |
|---|---|
| FECS 微码 | 32 KB, MD5 `ea8eb3c46165b00421896eef45d1070a` |
| GPCCS 微码 | 16 KB, MD5 `784c08e5a8fbfe9c8b300aa2b88e8116` |
| FECS/GPCCS 安全模式 | LIGHT SECURE (`security_model=2`) |
| Falcon ISA | fuc6, RV64 (`core_rev=6`) |
| TC 实测吞吐 | 0.60 TFLOPS (mma) vs 5.77 (FP16x2) → 慢 9.6× |
| 结论 | TU117 **无 Tensor Core**，HMMA 由 FP16 单元模拟 |
