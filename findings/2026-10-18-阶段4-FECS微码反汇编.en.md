## 1. Toolchain working

```
apt install cmake flex bison libxml2-dev libpciaccess-dev pkg-config g++
git clone --depth 1 https://github.com/envytools/envytools   (11 MB)
cmake -DDISABLE_HWTEST=ON -DDISABLE_NVA=ON -DDISABLE_VDPOW=ON .
```

**Pitfalls hit**:
1. `CMakeLists.txt` has `project()` on the first line and `cmake_minimum_required` on the second → changed to 3.5

3. envydis output contains **ANSI colour codes**, requiring `-n` to disable, otherwise every regex fails to match

**Final command**:

## 2. Disassembly result

**11,401 lines, 1.3 MB**, `-V fuc6` matching `core_rev=6` exactly.

### Entry point (0x0)

```asm
00000000: mov $r0 0x2000        ; stack top 0x2000
00000005: mov $sp $r0           ; set the stack pointer
00000008: clear b32 $r10
0000000a: lcall 0x6ca0          ; call main (located at 0x6ca0)
0000000e: exit                  ; returning halts
```

**Structurally isomorphic to the community's AD102 analysis** (AD102: stack top 0x2800 → `lcall 0x7747` → halt);
the differences come only from the generation (DMEM size, function layout).

## 4. Sample code (writing the 0x20600 series)

```asm
00000076: mov $r9 0x20600          ; target register
0000007a: extr $r10 $r14 0x3:0x3   ; extract a bitfield
0000007d: iowr I[$r9] $r15         ; write
00000080: iowr I[$r9] $r14         ; write again
00000083: bra b32 $r10 0x0 ne 0x8c
00000087: mov $r15 0x2
00000089: iowr I[$r9] $r15         ; conditional write
0000008c: ret
```

This is the typical "configure register + conditional branch" pattern.

## 5. Next steps

1. **Determine what the `0x20000` segment belongs to**:
   - check envytools `rnndb/` or nouveau's `NV_PGRAPH_*` / `NV_PGPC_*` definitions
   - decide whether it is GPC/SM-level configuration (if so, strongly correlated with TC)
2. **Locate TC-related writes**:
   - among the 379 writes in the 0x20000 segment, look for "grouped configuration" patterns
   - using the SM count (14), check whether an initialization sequence loops per SM
3. **Dump the GPCCS microcode**:
   - GPCCS directly manages the SMs inside a GPC, so TC configuration is more likely there
   - the GPCCS Falcon base must be located separately
