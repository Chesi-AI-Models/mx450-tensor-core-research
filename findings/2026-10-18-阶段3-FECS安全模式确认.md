# 🔴 阶段 3 · FECS 安全模式确认：LIGHT SECURE (LS)

**简体中文** | [繁體中文](2026-10-18-阶段3-FECS安全模式确认.zh-TW.md) | [English](2026-10-18-阶段3-FECS安全模式确认.en.md)

## 一、寄存器读取结果

卸载驱动后直接 mmap BAR0，读 FECS Falcon 实例（基址 `0x409000`）：

```
CPUCTL  (0x100) = 0x00000010   started=0  halted=1
HWCFG   (0x108) = 0x40204080   IMEM_SIZE 字段 = 128
DMACTL  (0x10c) = 0x00000005   secure_stat=0
HWCFG1  (0x12c) = 0x80104126
```

## 二、HWCFG1 解码（关键）

`0x80104126` 低字节 `0x26 = 0b0010_0110`：

| 字段 | bits | 值 | 含义 |
|---|---|---|---|
| `core_rev` | 3:0 | `0b0110` = 6 | **Falcon v6（fuc6）** |
| `security_model` | 5:4 | `0b10` = **2** | **LIGHT (LS)** |
| `core_rev_subversion` | 7:6 | `0b00` = 0 | subversion 0 |

## 三、三重交叉印证

1. **`security_model = 2`** → 按 `dev_falcon_v4.h` 与 nova-core 的 `FalconSecurityModel` 枚举，
   `2 = Light`（0=None/NS, 2=Light/LS, 3=Heavy/HS）
2. **`core_rev = 6`** → 与 cracker 社区对 AD102 FECS 的逆向笔记一致（该文使用
   `envydis -m falcon -V fuc6` 反汇编，9797 条指令全部注释）
3. **`secure_stat = 0`**（DMACTL bit 7）→ 当前不处于安全 DMA 传输态

**结论：MX450 的 FECS Falcon 运行在 Light Secure 模式，不是 Heavy Secure。**

## 四、这意味着什么

NVIDIA 官方对 LS 的描述：

> "**Light Secure (LS)**: In this mode, the microprocessor has more privileges than NS but
> fewer than HS. **Some of the microprocessor state is visible to host software to ease
> debugging.** The only way to enable this mode is by HS microcode enabling LS mode."

对比 HS：

> "**Heavy Secure (HS)**: the microprocessor is a **black box** — it's **not possible to read
> or write any Falcon internal state or Falcon registers from outside the Falcon**."

**这是今晚最重要的一个判断翻转**：

- 若为 HS → IMEM 完全不可读，此路当场终结
- **实际为 LS → 部分内部状态对 host 可见，IMEM 存在被读取的可能**

## 五、当前障碍：驱动卸载导致 Falcon 复位

```
IMEM 端口 0-3:  IMEMC=0  IMEMD=0  IMEMT=0
DMEM 端口 0-3:  DMEMC=0  DMEMD=0
CPUCTL: halted=1, started=0
```

**驱动卸载时 Falcon 被 reset，微码从 IMEM 中被清除。**

所以要读 IMEM，必须**在驱动运行时**访问 BAR0 —— 与 P3 阶段同样的矛盾，
解法同样明确：**用内核模块 `ioremap`**。

## 六、下一步（唯一动作）

写 `mx450_p4.c`，在驱动运行时：

1. `ioremap(BAR0 + 0x409000, 0x1000)`
2. 读 `HWCFG1 (0x12c)` 确认仍为 LS（驱动运行时可能不同）
3. 读 `IMEMC (0x180)` 当前值，看 `secure` 位（bit 28）
4. 若 `secure=0`：
   - 设置 `IMEMC = offs`（低 16 位为 block/word 偏移）
   - 读 `IMEMD (0x184)` 得到指令字
   - 逐块 dump IMEM
5. 若 `secure=1`：LS 模式下 secure IMEM 不可读，需另寻途径

**风险**：写 `IMEMC` 会改变 Falcon 的访问端口状态。缓解措施：
- 先只读当前值
- 保存原值，读完恢复
- 优先使用 port 3（通常驱动不用）
