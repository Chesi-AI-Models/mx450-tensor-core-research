# 🔴 階段 3 · FECS 安全模式確認：LIGHT SECURE (LS)

## 一、暫存器讀取結果

卸載驅動後直接 mmap BAR0，讀 FECS Falcon 實例（基底 `0x409000`）：

```
CPUCTL  (0x100) = 0x00000010   started=0  halted=1
HWCFG   (0x108) = 0x40204080   IMEM_SIZE 欄位 = 128
DMACTL  (0x10c) = 0x00000005   secure_stat=0
HWCFG1  (0x12c) = 0x80104126
```

## 二、HWCFG1 解碼（關鍵）

`0x80104126` 低位元組 `0x26 = 0b0010_0110`：

| 欄位 | bits | 值 | 含義 |
|---|---|---|---|
| `core_rev` | 3:0 | `0b0110` = 6 | **Falcon v6（fuc6）** |
| `security_model` | 5:4 | `0b10` = **2** | **LIGHT (LS)** |
| `core_rev_subversion` | 7:6 | `0b00` = 0 | subversion 0 |

## 三、三重交叉印證

1. **`security_model = 2`** → 依 `dev_falcon_v4.h` 與 nova-core 的 `FalconSecurityModel` 列舉，
   `2 = Light`（0 = None/NS, 2 = Light/LS, 3 = Heavy/HS）
2. **`core_rev = 6`** → 與 cracker 社群對 AD102 FECS 的逆向筆記一致（該文使用
   `envydis -m falcon -V fuc6` 反組譯，9797 條指令全部註解）
3. **`secure_stat = 0`**（DMACTL bit 7）→ 目前不處於安全 DMA 傳輸態

**結論：MX450 的 FECS Falcon 執行在 Light Secure 模式，不是 Heavy Secure。**

## 四、這意味著什麼

NVIDIA 官方對 LS 的描述：

> "**Light Secure (LS)**: In this mode, the microprocessor has more privileges than NS but
> fewer than HS. **Some of the microprocessor state is visible to host software to ease
> debugging.** The only way to enable this mode is by HS microcode enabling LS mode."

對比 HS：

> "**Heavy Secure (HS)**: the microprocessor is a **black box** — it's **not possible to read
> or write any Falcon internal state or Falcon registers from outside the Falcon**."

**這是今晚最重要的一個判斷翻轉**：

- 若為 HS → IMEM 完全不可讀，此路當場終結
- **實際為 LS → 部分內部狀態對 host 可見，IMEM 存在被讀取的可能**

## 五、目前障礙：驅動卸載導致 Falcon 重置

```
IMEM 埠 0-3:  IMEMC=0  IMEMD=0  IMEMT=0
DMEM 埠 0-3:  DMEMC=0  DMEMD=0
CPUCTL: halted=1, started=0
```

**驅動卸載時 Falcon 被 reset，微碼從 IMEM 中被清除。**

所以要讀 IMEM，必須**在驅動執行時**存取 BAR0 —— 與 P3 階段同樣的矛盾，
解法同樣明確：**用核心模組 `ioremap`**。

## 六、下一步（唯一動作）

寫 `mx450_p4.c`，在驅動執行時：

1. `ioremap(BAR0 + 0x409000, 0x1000)`
2. 讀 `HWCFG1 (0x12c)` 確認仍為 LS（驅動執行時可能不同）
3. 讀 `IMEMC (0x180)` 目前值，看 `secure` 位（bit 28）
4. 若 `secure=0`：
   - 設定 `IMEMC = offs`（低 16 位為 block/word 偏移）
   - 讀 `IMEMD (0x184)` 得到指令字
   - 逐塊 dump IMEM
5. 若 `secure=1`：LS 模式下 secure IMEM 不可讀，需另尋途徑

**風險**：寫 `IMEMC` 會改變 Falcon 的存取埠狀態。緩解措施：
- 先只讀目前值
- 儲存原值，讀完還原
- 優先使用 port 3（通常驅動不用）
