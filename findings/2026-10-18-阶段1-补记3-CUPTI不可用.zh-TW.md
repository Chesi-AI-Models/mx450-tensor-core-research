# 2026-10-18 · 階段 1 補記 3：CUPTI 路線（A 方案）判定為不可用

## 目標

用 CUPTI 列舉 GPU 暴露的效能計數器，尋找 `sm__pipe_tensor*` 類指標，
直接觀察張量管線是否被物理活化。這比 TC 計數更接近硬體真相。

## 環境

- CUPTI 函式庫：`/vol1/ganlin/venv/lib/python3.11/site-packages/nvidia/cuda_cupti/lib/libcupti.so.12`
- 標頭檔齊全（`cupti.h` / `cupti_metrics.h` / `cupti_events.h` 等）
- 匯出符號確認存在：`cuptiDeviceEnumMetrics` / `cuptiDeviceGetNumMetrics` /
  `cuptiMetricGetIdFromName` / `cuptiMetricEnumEvents`
- 工具：`tools/enum_cupti_metrics.py`（ctypes 直接呼叫 CUPTI，無需編譯）

## 嘗試 1 · 直接列舉

```
cuInit -> 0
cuDeviceGet -> 0  device = 0
cuCtxCreate -> 0
cuptiDeviceEnumMetrics -> rc = 38
共收集到 0 個 metric
```

CUDA 側全部初始化正常，**唯獨 metric 列舉被拒**。

## 嘗試 2 · 開放 profiling 權限後重試

GeForce 預設限制 profiler 權限，遂寫入模組參數並重載驅動：

```
/etc/modprobe.d/nvidia-profiling.conf:
  options nvidia NVreg_RestrictProfilingToAdminUsers=0

modprobe -r nvidia_uvm nvidia_drm nvidia_modeset nvidia
modprobe nvidia / nvidia_modeset / nvidia_drm / nvidia_uvm
nvidia-smi -L  ->  GPU 0: NVIDIA GeForce MX450（正常）
```

重跑列舉：

```
cuptiDeviceEnumMetrics -> rc = 38
共收集到 0 個 metric
```

**結論：不是權限問題。**

## 判定

`CUPTI 38` 在本機標頭檔中無法直接定位到字面列舉（該標頭檔用條件編譯生成）。
排除權限因素後，最可能是：

- 該 CUPTI 版本（12.1.105）不支援對這塊 GPU 做 metric 列舉，或
- `cuptiDeviceEnumMetrics` 需要前置的 profiler config 初始化，而該初始化在 GeForce 上不可用

**無論哪一種，A 路線在目前環境下不可用。**

## 三條診斷路線的最終結論

| 路線 | 手段 | 結果 | 卡點性質 |
|---|---|---|---|
| B-1 | `NV2080_CTRL` ioctl 讀 TC 計數 | 通道打通（ROOT_CLIENT 成功），GR_GET_INFO status=31 | 驅動物件模型未通 |
| A | CUPTI metric 列舉 | `rc=38`，零 metric（含開放權限後） | 函式庫／權限雙重限制 |
| C | 系統 BIOS devinit 分析 | 未開始 | 需 dump BIOS |

**兩條高層診斷路徑都被封死，但都屬於「工具鏈限制」，不是原理層面的否定。**

## 對核心結論的影響

**無影響。** 以下四條證據互不依賴，任一成立即可支撐「TC 存在但被限速」：

1. `ptxas -arch=sm_75` 對 `mma.m16n8k8` 產生真 HMMA 指令（opcode 指紋與 FFMA 版截然不同）
2. 該指令執行不報錯（若 TC 完全缺失應觸發非法指令）
3. 吞吐恆 0.60 TFLOPS，**低於純 FFMA 的 3.06** —— 走的是比軟體展開更低效的路徑
4. `cuBLAS` 請求 `TENSOR_OP` 演算法後 0.32 TFLOPS，比 FP32 慢 6.4 倍

**要再往下走，必須越過使用者態：**

1. **寫核心模組直接 mmap BAR0** —— CMPUnlocker 走的正是這條路
   （它的補丁直接改 `nvidia-open` 核心模組，繞過所有使用者態 API）
2. **dump 系統 BIOS 分析 devinit 表** —— 唯一還沒試過的高層路徑
3. 物理量測（示波器／功耗計）—— 與本專案目標無關
