## 关键设计：no-fault 读取

`kernel/mx450_p2.c` 的核心安全机制：

```c
ret = copy_from_kernel_nofault(buf, (void *)target_addr, sizeof(buf));
if (ret) { pr_err("... failed: %d\n", ret); return -EFAULT; }
```

- 地址由用户态读 `/proc/kallsyms` 得到，通过 `module_param` 传入
- **全程不调用 `kallsyms_lookup_name`**（P1 中被证明会 oops）
- `copy_from_kernel_nofault` 在页错误时返回错误码而非崩溃
- 只读，不调用目标函数

### 手工反汇编

```asm
0f 1f 40 d6        nop    DWORD PTR [rax-0x2a]      ; 多字节 NOP，函数对齐
0f 1f 44 00 00     nop    DWORD PTR [rax+rax*1+0x0]
48 83 ec 10        sub    rsp, 0x10                  ; 建立栈帧
48 85 ff           test   rdi, rdi                  ; 检查第 1 个参数
75 14              jne    0x...                      ; 非空则跳转
48 8b 05 cf ea e6 ee  mov  rax, [rip-0x1115...]     ; 加载全局变量
85 d2              test   edx, edx
75 7a              jne    ...
48 83 c4 ...       add    rsp, ...
```

**可读出的信息**：
1. 这是真实的 C 函数（有栈帧、参数检查、全局变量访问）
2. 遵循 **System V AMD64 ABI**：第 1 参数在 `rdi`，第 3 参数在 `edx`
3. `test rdi, rdi; jne` → **第 1 个参数是指针且会判空**
4. `test edx, edx` → 第 3 个参数是 32 位值，也会被检查
